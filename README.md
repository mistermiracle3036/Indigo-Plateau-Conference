# Indigo Plateau Conference

A mod for [gen1recomp](https://github.com/bryanthaboi/gen1recomp).

Beating the Elite Four is supposed to be the end. The Indigo Plateau
Conference makes it the qualifier. Register on Route 22 and fight three
rounds against a field of guest challengers — a different draw every
run, so no two tournaments are the same.

> **Not released yet.** This repository is private and under active
> development. There is no public release to install, and the version
> here changes often. The README gets its full treatment — features,
> screenshots, options, install steps — when the mod is ready to ship.

## Status

**v0.1.0 — scaffold.** The mod loads and announces its version. No
