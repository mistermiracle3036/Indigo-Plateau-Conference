## What this mod ships

No binary assets. Every character the Colosseum circuit fields is drawn
using art already present in the player's own imported Gold cache — this
mod ships recipes and references, never pixels.

## Built on

- **[gen1recomp](https://github.com/bryanthaboi/gen1recomp)** — the engine
  this mod runs on.
- **[pret/pokecrystal](https://github.com/pret/pokecrystal)** and
  **[pret/pokered](https://github.com/pret/pokered)** — disassembly research.
  Used as reference for map ids, trainer classes and badge constants; no
  code or data copied.

## Influences

- **Court of Noctowl** (Mister Miracle) — the owned-NPC pattern on Gold
  (the `world.interacted` fall-through) was proven there first, and this
  mod uses the same approach. Not copied wholesale; the working shape is
  credited because it saved a build round.
